# AIS3_JR 密碼學解題輔助工具 — 使用說明
[toc]

## 步驟

1. cd 進資料夾(ex: cd /Users/***/Docker/2026-AIS3_JR)
2. docker compose up --build
3. 瀏覽器打開 **http://localhost:8080**。
4. 上方導覽列選擇要用的功能。
5. 填入欄位 → 按執行 → 結果顯示在下方。

確認後端有沒有活著：打開 http://localhost:8080/api/health ，
看到 `{"success":true,"data":{"status":"ok"},"error":null}` 就代表正常。

---

## 功能總覽

| 分頁 | 做什麼 | 方向 |
| --- | --- | --- |
| 凱撒密碼 | 位移還原、或一次列出 26 種位移 | 解密 / 暴力破解 |
| 維吉尼亞 | 用金鑰字加解密 | 加密＋解密 |
| 欄位轉換 | 依金鑰重排字元順序 | 加密＋解密 |
| Base64 | 文字與 Base64 互轉 | 編碼＋解碼 |
| RSA 破解 | 已知 N/e/c，分解 N 反推明文 | 破解 |
| Cisco IOS Type 7 | 還原 Cisco 設定檔裡的 Type 7 密碼 | 還原 |

## 凱撒密碼
**怎麼用**
- 已知位移量：輸入密文 + 位移量（0–25），得到明文。
- 不知道位移量：用「暴力破解」，它會一次列出全部 26 種位移的結果，
  你自己挑出讀得通的那一行。

**範例**
```
密文：I_love_AIS3_JR   位移：3   → F_ilsb_XFP3_GO
```

**注意**
- 位移量只吃 0–25 的整數。
- 只有英文字母會被位移，空白、標點、數字原樣保留。
- ROT13（位移 13）有個特性：對同一段文字做兩次位移 13 會變回原文。

---

## 維吉尼亞


**怎麼用**
- 文字：要處理的內容。
- 金鑰：純英文字母的單字（例如 `LEMON`）。
- 模式：加密或解密。

**範例**
```
文字：ATTACKATDAWN   金鑰：LEMON   模式：加密   → LXFOPVEFRNHR
```
把 `LXFOPVEFRNHR` 配同一把金鑰、模式改「解密」，應還原回 `ATTACKATDAWN`。

**注意**
- 非英文字母（空白、標點、數字）會原樣保留，而且**不消耗金鑰字元**。
- 空金鑰、含非字母的金鑰都應該被擋下並顯示錯誤。

---

## 欄位轉換

**怎麼用**
- 文字：要處理的內容。
- 金鑰：純英文字母（例如 `ZEBRAS`），金鑰長度決定分成幾欄。
- 模式：加密或解密。

**範例（長度剛好整除，最單純）**
```
文字：ATTACKATDAWN   金鑰：MATH   模式：加密   → TKAATNACDTAW
```
（12 個字元 ÷ 4 欄 = 剛好 3 列，沒有補位問題。）

**注意**
1. **加密會移除所有空白字元**，所以解密後救不回原本的斷詞（換行、空格）。

---

## Base64

**範例**
```
編碼：hello           → aGVsbG8=
解碼：aGVsbG8=        → hello
```

**注意**
- 含中文或表情符號時，會先轉成 UTF-8 再編碼，屬正常行為。
- 解碼欄要貼合法的 Base64（長度、`=` 補位、字元集都要對），否則會報錯。

---

## RSA 破解
**怎麼用**：三個欄位都填十進位正整數
- 模數 N
- 公鑰 e
- 密文 c

**範例（可還原成可讀文字）**
```
模數 N：2252487907
公鑰 e：17
密文 c：41211461
→ 明文 AIS3
```
> 這組是把文字 `AIS3` 當作訊息加密後產生的。工具會分解 N、反推出數字 m，
> 再把 m 轉成文字。**前提是這串 c 本來就是某段文字加密來的**；
> 如果 c 對應的數字轉不成可讀文字，工具會改成顯示帶有 m 值的錯誤訊息，
> 而不是留空白。

**教科書純數字範例**
```
N：3233   e：17   c：2790     （對應數字 65）
N：3675787   e：17   c：644362 （對應數字 123456）
```

**注意**
- N 有位數上限（約 25 位）。超過會被擋下，因為分解會太慢。
- 這幾種輸入應該要出現明確錯誤，而不是卡住或崩潰：
  - N 是質數或本身就是 c（c 必須小於 N）。
  - e 與 φ(N) 不互質（求不出解密指數）。
  - N/e/c 填了非正整數。

## Cisco IOS Type 7

**怎麼用**
- 加密字串：一串十六進位（開頭兩碼是位移偏移量，其餘是 XOR 後的值）。
- 按「還原密碼」→ 顯示原始明文。

**範例**
```
02272D6858   → AIS3
060506324F41 → cisco
```

**注意**
- 開頭兩碼是偏移量。同一段明文用不同偏移量會產生完全不同的字串，
  但都應該還原成同一個明文。
- 含非十六進位字元、或長度是奇數（無法兩兩配對）的輸入應該報錯。

## 疑難排解

| 症狀 | 可能原因 |
| --- | --- |
| 顯示「伺服器回應格式錯誤」 | 後端沒回 JSON（多半是路由打錯或後端沒起來），先測 `/api/health`。 |
| 顯示「找不到路由」 | 該功能的 API 尚未實作或路徑拼錯。 |
| 欄位轉換解密救不回原文 | 多半是長度非整除時的補位／切割問題，見該節說明。 |
| RSA 一直轉不出來 | N 太大（超過位數上限）或本來就無法分解。 |
| Base64 解碼失敗 | 輸入不是合法的 Base64 字串。 |
